# OpenFlux Panel

Веб-панель для [OpenFlux](https://github.com/p1neappleXpress/OpenFlux): создание exit-подключений кнопками,
автозапуск каждого через systemd, ссылка `openflux://` и QR для клиента.

## Установка (одна строка, от root)

```bash
git clone --depth 1 https://github.com/1hx74/openflux-panel /opt/openflux && bash /opt/openflux/install.sh
```

Скрипт:
1. спросит архитектуру (список берётся из последнего релиза OpenFlux: amd64, arm64 и т.д.) и скачает бинарник в `/opt/openflux/openflux`;
2. спросит, есть ли сертификаты. Если да — путь к `fullchain.pem` / `privkey.pem` и домен (панель на HTTPS по домену); если нет — панель по IP по HTTP;
3. сгенерирует логин, пароль, секретный путь и порт выше 9000;
4. поставит панель в автозапуск (`openflux-panel.service`) и выведет в консоль готовый адрес, логин и пароль.

Откройте выведенный порт в firewall. Без сертификата пароль идёт по HTTP открытым текстом — лучше использовать домен с сертификатом.

## Подключения

В панели → «Новое подключение»:

- **Свободный запуск** — впишите аргументы, они запустятся как `./openflux <аргументы>`.
- **Телемост пример** — вставьте ссылку встречи, кнопка подставит
  `--role=exit --mode=l4 --transport=telemost --url="<ссылка>" --debug`.
- **CUPS пример** — `--role=exit --mode=l4 --transport=cupsonline`. Узел выдаёт base64-код; панель забирает его из логов,
  сохраняет в подключении и при следующих запусках добавляет `--url=<код>`.

Каждое подключение — отдельный systemd-сервис `openflux-c-<id>` (автозапуск, перезапуск при падении).
Кнопка «Ссылка / QR» показывает `openflux://` ссылку и QR для клиента. Ссылка берётся из вывода узла
(строки вида `openflux://...`); если узел её не напечатал, показывается base64-код, и QR строится по нему.

## Полное удаление одной командой

```bash
bash /opt/openflux/uninstall.sh
```

Останавливает и удаляет все сервисы панели и подключений и стирает `/opt/openflux`.

## Структура

Всё лежит в `/opt/openflux`: `panel.py`, `install.sh`, `uninstall.sh`, `openflux` (бинарник), `venv/`, `config.json`, `connections.json`.
Вне этой папки только systemd-юниты `openflux-panel.service` и `openflux-c-*.service`; их удаляет `uninstall.sh`.

## Замечания

- Панель работает от root (нужно для systemd) — держите секретный путь и пароль в тайне.
- Формат `openflux://` и вывод узла разбираются по логам; точный формат определяет ядро OpenFlux. Если у узла нужен iptables-фильтр RST (режим raw), настройте его отдельно по вики OpenFlux.
